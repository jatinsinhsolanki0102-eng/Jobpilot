 1. PLATFORM DECISION
 -----------------------------------------------------------------
 Railway was chosen. Free trial: one-time $5 credit, 30 days,
 NO CREDIT CARD REQUIRED. After the trial, Railway reverts to the
 Free plan with $1/month of credit - not enough to keep this stack
 (2 services + Postgres) running 24/7, so the trial is a working
 deployment to validate the app. Long-term hosting can be decided
 after (paid Railway Hobby, Oracle Free VM, or an old machine).

 3. DEPLOY STEPS (Railway dashboard, no CLI needed)
 -----------------------------------------------------------------
   1. Push repo to GitHub (done: github.com/jatinsinhsolanki0102-eng/Jobpilot).
   2. Go to railway.com -> Login with GitHub (free trial, no card).
   3. New Project -> Deploy from GitHub repo -> select Jobpilot.
   4. Provision PostgreSQL: click + New -> Database -> PostgreSQL.
      Railway auto-injects DATABASE_URL into the backend service.
    5. Backend service (the container built from backend/Dockerfile):
       - Settings -> General -> Root Directory = backend
       - Variables tab, add:
           GROQ_API_KEY          = <from backend/.env>
           TELEGRAM_BOT_TOKEN    = <from backend/.env>
           TELEGRAM_BOT_USERNAME = JobPilot_Update_AI_Bot
           SECRET_KEY            = <long random string>
           SCHEDULER_ENABLED     = true
           CORS_ORIGINS          = ["https://<frontend-domain>"]
           ADZUNA_APP_ID         = <from backend/.env>
           ADZUNA_APP_KEY        = <from backend/.env>
         (DATABASE_URL comes automatically from the Postgres plugin)
       - NOTE: ADZUNA_APP_ID/APP_KEY enable the Adzuna source (a rich stream
         of Indian jobs). They are NOT in the Docker image, so they must be
         added here or Adzuna is silently skipped.
       - OPTIONAL anti-bot cookies (only needed for Naukri/Wellfound, which
         block datacenter IPs with Akamai/DataDome):
           NAUKRI_COOKIES        = "name=value; name2=value2"
           WELLFOUND_COOKIES     = "name=value; name2=value2"
           SCRAPER_PROXY         = <residential proxy URL, optional>
       - Deploy. Check logs for "Database ready",
         "Background scheduler started", "Telegram bot polling started".
         Open the public URL -> /health returns {"status":"ok",...}.
   6. Frontend service (built from frontend/Dockerfile):
      - Settings -> General -> Root Directory = frontend
      - Variables tab, add: NEXT_PUBLIC_API_URL = https://<backend-domain>
        (copy the backend public URL, e.g. https://<name>.up.railway.app)
      - Redeploy once the variable is set (NEXT_PUBLIC_* is baked
        at build time).
   7. Verify end-to-end:
      - Open frontend URL, register, upload resume, browse ranked jobs.
      - Message the Telegram bot: /start then /link <code> from the app.
      - Watch backend logs for a scheduled scan.

 Environment variables summary (never commit secrets):
   Backend:  DATABASE_URL, GROQ_API_KEY, TELEGRAM_BOT_TOKEN,
             TELEGRAM_BOT_USERNAME, SECRET_KEY, SCHEDULER_ENABLED, CORS_ORIGINS,
             ADZUNA_APP_ID, ADZUNA_APP_KEY,
             (optional) NAUKRI_COOKIES, WELLFOUND_COOKIES, LINKEDIN_COOKIES,
             UNSTOP_COOKIES, SCRAPER_PROXY
   Frontend: NEXT_PUBLIC_API_URL

 4. DATABASE NOTES
 -----------------------------------------------------------------
   - Tables are created automatically on first start (app.seed uses
     create_all + seeds 15 sample jobs) - no manual migration.
   - Railway free-trial databases/volumes are deleted 30 days after
     the trial credit expires - export before then if you keep going.

 5. TRIAL COST / TIMELINE
 -----------------------------------------------------------------
   - $5 one-time credit, up to 30 days. This stack (2 web services +
     Postgres, always-on) consumes roughly $3-6/month, so the trial
     may last ~1-4 weeks depending on traffic/CPU.
   - After credit runs out: revert to Free plan ($1/month credit,
     services shut down if they exceed it) or upgrade to Hobby
     ($5/month, requires a credit card).

 6. OTHER PLATFORMS (for reference)
 -----------------------------------------------------------------
   - RENDER: blueprints in render.yaml; free tier SLEEPS after 15 min
     idle -> bot stops. Paid Starter ~$7/mo keeps it always-on.
   - ORACLE CLOUD: Always Free ARM VM (4 OCPU / 24 GB) runs 24/7
     for $0; needs a credit card just for signup verification.
   - OLD LAPTOP / RASPBERRY PI: run docker-compose.yml at home for
     $0 with Cloudflare Tunnel for HTTPS; no card needed.
   - NOT recommended: Vercel (serverless breaks scheduler + bot),
     shared cPanel hosting.
