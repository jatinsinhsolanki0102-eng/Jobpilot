 3. DEPLOY STEPS
 -----------------------------------------------------------------

 ========== STEP 1: NEON DATABASE (do first) ==========
 1. Go to neon.tech -> Sign up with GitHub (free, no card)
 2. Create new project:
    - Project name: jobpilot
    - Region: AWS US East (or nearest to your users)
 3. When project is created, copy the connection string:
    - Format: postgresql://username:password@ep-xxx.us-east-2.aws.neon.tech/dbname?sslmode=require
    - IMPORTANT: Keep this safe, you'll need it for Belmo

 ========== STEP 2: BELMO BACKEND ==========
 1. Go to belmo.io -> Login with GitHub
 2. Install Belmo GitHub App on your repository
 3. Click "New Service" -> Select your JobPilot-AI repo
 4. Set Root Directory to: backend
 5. Belmo auto-detects Python/FastAPI
 6. Add these environment variables in Belmo dashboard:
    - DATABASE_URL = <paste Neon connection string from Step 1>
    - SECRET_KEY = <generate: run openssl rand -hex 32>
    - GROQ_API_KEY = <your Groq API key from console.groq.com>
    - CORS_ORIGINS = ["https://your-app.vercel.app"]
    - SCHEDULER_ENABLED = true
    - TELEGRAM_BOT_TOKEN = <from @BotFather>
    - TELEGRAM_BOT_USERNAME = JobPilotAIBot
    - ADZUNA_APP_ID = <optional, free from developer.adzuna.com>
    - ADZUNA_APP_KEY = <optional>
    - REDIS_URL = redis://localhost:6379/0 (not needed, Belmo doesn't provide Redis free)
    - NAUKRI_COOKIES = <optional, for scraping>
    - WELLFOUND_COOKIES = <optional, for scraping>
 7. Deploy
 8. Check logs for: "Database ready", "Background services started"
 9. Copy your backend URL (e.g., https://your-app.belmo.app)

 ========== STEP 3: VERCEL FRONTEND ==========
 1. Go to vercel.com -> Login with GitHub
 2. Click "Add New" -> "Project"
 3. Import your JobPilot-AI repository
 4. Set Root Directory to: frontend
 5. Framework: Next.js (auto-detected)
 6. Add environment variable:
    - NEXT_PUBLIC_API_URL = https://your-app.belmo.app (from Step 2)
 7. Click Deploy
 8. Wait for build to complete
 9. Copy your frontend URL (e.g., https://your-app.vercel.app)

 ========== STEP 4: FINAL UPDATE ==========
 1. Go back to Belmo dashboard -> Backend service -> Variables
 2. Update CORS_ORIGINS with your actual Vercel URL:
    CORS_ORIGINS = ["https://your-actual-vercel-url.vercel.app"]
 3. Redeploy the backend service

 9. TROUBLESHOOTING
 -----------------------------------------------------------------
 - CORS errors: Update CORS_ORIGINS in Belmo with Vercel domain
 - Database error: Ensure Neon URL has ?sslmode=require
 - Telegram bot not responding: Check TELEGRAM_BOT_TOKEN is correct
 - Scheduler not running: Check SCHEDULER_ENABLED=true in Belmo
 - Cold starts: Normal on free tier, first request may take 30s
