 3. BELMO DEPLOYMENT ISSUES ENCOUNTERED
 -----------------------------------------------------------------

 ISSUE 1: Nixpacks can't detect Python
   Error: "Nixpacks failed to detect the application type"
   Cause: Root directory has both frontend (Node) and backend (Python).
          Nixpacks detects Node from package.json at repo root.
   Fix Attempt 1: Set Root Directory to ./backend -> Did not work
   Fix Attempt 2: Set Root Directory to backend -> Did not work
   Fix Attempt 3: Created nixpacks.toml in backend/ -> Did not work
   Fix Attempt 4: Created root-level Dockerfile -> WORKED!

   ROOT CAUSE: Belmo's Nixpacks ignores the Root Directory setting
   when detecting application type. It always scans the repo root.

 ISSUE 2: Dockerfile CMD parsing error
   Error: "/bin/bash: -c: option requires an argument"
   Cause: CMD ["exec", "form"] not compatible with Belmo's shell
   Fix: Changed to shell form CMD: uvicorn app.main:app ...
   Status: App shows Running but health check returns 503

 ISSUE 3: Environment variables not set
   The backend crashes on startup without DATABASE_URL and SECRET_KEY
   These MUST be added in Belmo Environment tab before deployment works
